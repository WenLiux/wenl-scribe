# GitHub 图片与演示素材清单

最终截图应使用可公开的视频示例，并避免显示 API Key、个人历史记录或本机路径。

建议文件：

```text
docs/assets/home.png
docs/assets/task-progress.png
docs/assets/result-summary.png
docs/assets/result-transcript.png
docs/assets/floating-left.png
docs/assets/floating-right.png
docs/assets/markdown-export.png
docs/assets/demo.mp4
```

截图要求：

- 首页：品牌、输入框和本地转录定位清楚；
- 任务页：展示真实阶段和进度，但不包含隐私信息；
- 总结页：展示总体总结、观点、原文依据和左侧浮窗；
- 逐字稿页：展示时间戳、原文阅读和右侧浮窗；
- Markdown：展示视频信息表、可点击时间戳和中文文件名；
- 图片宽度建议至少 1440 像素，避免浏览器标签、收藏夹和账号信息；
- 演示视频控制在 30–60 秒，首屏先展示最终结果，再回到输入流程。

测试完成后再采集最终素材，避免截图与正式版本不一致。
