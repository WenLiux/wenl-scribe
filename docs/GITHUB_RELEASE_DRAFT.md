## Release 正文

```markdown
## 所见所听，皆可留文

留文是一款本地优先的 B 站视频转录与内容整理工具。粘贴视频链接，即可获得带时间戳的逐字稿、可核对原文依据的内容总结，以及排版清晰的 Markdown 文件。

### 本次包含

- 公开字幕优先，无字幕时使用本机 Whisper 转录
- `small`、`medium`、`large-v3-turbo` 模型选择
- Gemini、SenseNova、OpenAI 和兼容接口总结
- 核心观点绑定原文依据与视频时间戳
- 总结页左侧迷你播放器、逐字稿页右侧迷你播放器
- 两个页面均可将播放器缩略为统一位置的按钮
- 逐字稿与总结分别导出 Markdown
- 导出文件使用“视频标题＋总结／逐字稿＋留文”命名
- 本地历史记录、失败恢复、重新总结和脱敏诊断

### 使用方法

1. 下载 `WENL-Scribe-Portable-v0.6.1-win-x64.zip`
2. 完整解压，不要在压缩包内直接运行
3. 双击 `WENL Scribe.exe`
4. 使用结束后，在系统托盘退出留文

首次使用某个 Whisper 模型时需要联网下载。

### 隐私

- 音频转录在本机完成
- 开启云端总结后，带时间戳逐字稿会发送给所选服务
- 历史记录、模型和配置默认保存在本机
- 当前版本不包含留文自建遥测或账户系统

### 已知限制

- 当前仅面向 64 位 Windows 10/11
- 内测包尚未完成代码签名，Windows 可能显示“未知发布者”
- CPU 转录速度取决于视频时长、模型和电脑配置
- 仅支持公开可访问且用户有权处理的内容

### 文件校验
```
