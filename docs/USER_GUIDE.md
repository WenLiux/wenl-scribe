# 留文 Windows 用户指南

## 安装与启动

1. 从 GitHub Releases 下载 `WENL-Scribe-Portable-<版本>-win-x64.zip`。
2. 将 ZIP 完整解压到普通文件夹，不要直接在压缩包内运行。
3. 双击 `WENL Scribe.exe`。
4. 浏览器会自动打开留文。
5. 若需要再次打开，右键系统托盘中的留文图标并选择“打开留文”。
6. 使用结束后，在托盘菜单选择“退出留文”。

当前内测版本尚未完成代码签名，Windows 可能显示“未知发布者”。请核对下载来源和 Release 页面提供的 SHA-256。

## 创建任务

1. 复制 B 站普通链接、`b23.tv` 短链或完整分享文案。
2. 粘贴到首页输入框。
3. 点击“开始留文”。
4. 等待链接解析、字幕检查、音频准备、转录和总结完成。

留文优先读取公开视频字幕；没有字幕时才启动本地 Whisper。

## 模型选择

| 模型 | 特点 | 适合场景 |
| :--- | :--- | :--- |
| `small` | 下载较小、速度较快 | 快速试用、配置较低的电脑 |
| `medium` | 速度和准确率折中 | 日常中文内容 |
| `large-v3-turbo` | 质量优先、资源占用更高 | 对准确率要求较高的长内容 |

首次使用某个模型时需要联网下载，后续会复用本机文件。

## 阅读结果

- “内容总结”展示总体总结、核心观点、原文依据和内容脉络。
- “完整转录”展示带时间戳的逐字稿。
- 点击时间戳可以让播放器定位到对应位置。
- 向下阅读时，总结页播放器默认悬浮在左侧，逐字稿页默认悬浮在右侧。
- 点击“缩略”后，播放器会变成统一位置的“视频”按钮。

## 下载 Markdown

切换到相应板块后点击“下载 Markdown”：

```text
视频标题总结留文.md
视频标题逐字稿留文.md
```

Markdown 中的时间戳可链接回原视频。重要内容仍应回看原视频核对。

## 配置总结 API

1. 打开右上角“设置”。
2. 选择 Gemini、SenseNova、OpenAI 或兼容接口。
3. 填写地址、模型和 API Key。
4. 点击“保存配置”。
5. 点击“测试连接”。

不开启 API 时，留文提供本地原文重点摘录。开启后，带时间戳逐字稿会发送给所选服务生成语义总结。

## 数据与卸载

便携版数据默认位于：

```text
%LOCALAPPDATA%\WENL Scribe\data
```

删除程序文件不会自动删除这里的历史任务、模型和配置。彻底清除前，请先备份需要保留的 Markdown。
