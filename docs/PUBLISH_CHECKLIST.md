- [ ] 安全问题的私下联系渠道

## 许可证决策

GitHub 官方说明：没有许可证时，默认版权法生效，其他人通常不能复制、分发或制作衍生作品；公开仓库用户仍可依 GitHub 条款查看和 fork。发布前应明确选择：

- MIT：限制少，允许商业使用和修改；
- Apache-2.0：宽松许可，并包含明确专利条款；
- 暂不开放授权：保留全部权利，但项目不属于真正意义上的开源软件。

不要在没有理解影响的情况下自动添加许可证。
