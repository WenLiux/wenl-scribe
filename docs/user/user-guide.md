# 留文 Windows 用户指南

## 安装与启动

1. 从 GitHub Releases 下载 `WENL-Scribe-Portable-<版本>-win-x64.zip`。
2. 将 ZIP 完整解压到普通文件夹，不要直接在压缩包内运行。
3. 双击 `WENL Scribe.exe`。
4. 浏览器会自动打开留文。
5. 若需要再次打开，右键系统托盘中的留文图标并选择“打开留文”。
6. 使用结束后，在托盘菜单选择“退出留文”。

当前内测版本尚未完成代码签名，Windows 可能显示“未知发布者”。请核对下载来源和 Release 页面提供的 SHA-256。

## 创建任务

1. 复制 B 站普通链接、`b23.tv` 短链或完整分享文案。
2. 粘贴到首页输入框。
3. 点击“开始留文”。
4. 等待链接解析、字幕检查、音频准备、转录和总结完成。

留文优先读取公开视频字幕；没有字幕时才启动本地 Whisper。

## 模型选择

| 模型 | 特点 | 适合场景 |
| :--- | :--- | :--- |
| `small` | 下载较小、速度较快 | 快速试用、配置较低的电脑 |
| `medium` | 速度和准确率折中 | 日常中文内容 |
| `large-v3-turbo` | 质量优先、资源占用更高 | 对准确率要求较高的长内容 |

首次使用某个模型时需要联网下载，后续会复用本机文件。

## 阅读结果

- “内容总结”展示总体总结、核心观点、原文依据和内容脉络。
- “完整转录”展示带时间戳的逐字稿。
- 点击时间戳可以让播放器定位到对应位置。
- 向下阅读时，总结页播放器默认悬浮在左侧，逐字稿页默认悬浮在右侧。
- 点击“缩略”后，播放器会变成统一位置的“视频”按钮。

## 下载 Markdown

切换到相应板块后点击“下载 Markdown”：

```text
视频标题总结留文.md
视频标题逐字稿留文.md
```

Markdown 中的时间戳可链接回原视频。重要内容仍应回看原视频核对。

## 配置总结 API

1. 打开右上角“设置”。
2. 选择服务商。
3. 输入 API Key。SenseNova 普通流程只需要 Key，不需要先填写地址或模型。
4. SenseNova 点击“连接并自动选择模型”；OpenAI、Gemini 或其他兼容服务先点击“保存配置”，服务支持模型列表时再点击“读取可用模型”。
5. 点击“测试连接”。该操作只发送一条很短的探测请求，不会把视频逐字稿发送给服务。

协议、API 地址和模型 ID 默认收进“高级设置”。能提供模型列表的服务会自动读取并显示账号可用模型；不提供标准列表接口的服务仍可使用默认模型，或在高级设置中手动填写模型 ID。留文内部按“协议”处理 API，而不是按模型名称写死适配。

### 商汤 SenseNova 接入 DeepSeek V4 Flash

这里使用的是“商汤平台接入 DeepSeek”的接口，不是 DeepSeek 官方接口。若要使用商汤账号中已开通的 DeepSeek V4 Flash：

1. 服务商选择“商汤 SenseNova”。
2. 在 SenseNova 控制台生成 `API_TOKEN` 并粘贴到密钥输入框；不要填写 Secret Key。
3. 点击“连接并自动选择模型”。留文会读取账号可见模型，优先选择允许对话的模型，并自动测试连接。

留文会自动尝试 SenseNova 官方兼容接口和旧版兼容网关；旧配置指向其他接口时，模型读取成功后也会迁移到可用接口。只有自动探测失败时，才需要在“高级设置”中检查协议和地址。

### 通用 OpenAI 兼容接口

留文按接口协议而不是按模型名称适配。OpenAI 和标准 OpenAI 兼容服务会尝试读取 `/models`；本地 Ollama 会读取 `/api/tags`。读取成功后可直接从模型下拉框选择。若服务不提供模型列表或返回 404，则在“高级设置”中手动填写模型 ID；这不代表总结接口本身不可用。

Gemini 官方 OpenAI 兼容接口支持 `/models`，保存 Key 后可以点击“读取可用模型”；如果使用的是不提供该接口的私有代理，再在“高级设置”中手动填写模型 ID。

不开启 API 时，留文提供本地原文重点摘录。开启后，带时间戳逐字稿会发送给所选服务生成语义总结。

## 数据与卸载

便携版数据默认位于：

```text
%LOCALAPPDATA%\WENL Scribe\data
```

删除程序文件不会自动删除这里的历史任务、模型和配置。彻底清除前，请先备份需要保留的 Markdown。
