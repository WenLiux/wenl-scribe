# 常见问题与故障排查

## 双击后没有打开页面

1. 检查系统托盘是否出现留文图标。
2. 右键图标，选择“打开留文”。
3. 确认程序已经完整解压。
4. 暂时关闭后重新启动，避免同时运行多个副本。

## Windows 提示未知发布者

当前内测包尚未完成代码签名。只从本仓库 Release 页面下载，并核对 SHA-256。若来源不明，请不要运行。

## 首次转录长时间停在加载模型

首次使用模型需要下载模型文件，时间取决于网络和模型大小。可以先在设置中选择 `small` 测试。

## 音频下载失败

可能原因：

- 视频需要登录、付费或特定地区权限；
- 视频不是公开可访问内容；
- B 站接口暂时不可用；
- 网络代理或安全软件阻止请求。

留文不会尝试绕过内容权限。

## 转录速度慢

当前默认使用 CPU 转录。长视频、大模型和配置较低的电脑会明显更慢。可以改用 `small` 或 `medium`。

## 总结内容与原视频不一致

1. 点击每条观点的时间戳和原文依据核对。
2. 先检查逐字稿是否准确。
3. 在设置中测试总结 API。
4. 使用“重新生成”只重做总结，无需重新转录。
5. 对重要内容不要只依赖自动总结。

## 总结 API 失败

- `401/403`：检查 API Key 是否有效。
- `404`：检查模型名称和 API 地址。
- `429`：可能达到速率或额度限制。
- 超时：稍后重试，或缩短视频长度。

如果“读取可用模型”返回 `404` 或提示服务不支持模型列表，先不要反复修改 API Key：打开“高级设置”，填写该服务真实的 API 地址和模型 ID，再保存并测试总结接口。Gemini 官方兼容地址支持模型列表，但部分私有代理可能没有实现该接口。

SenseNova 普通流程只需要粘贴控制台生成的 `API_TOKEN`，不要填写 Secret Key，然后点击“连接并自动选择模型”。留文会自动尝试官方兼容接口和旧版兼容网关；如果返回 `HTTP 403` 且商汤错误码为 `7`，含义是当前账号没有访问该接口或模型的权限，请在商汤控制台“订阅中心”开通对应 API/模型，或改用模型清单中已开通的 ID。

不要把 API Key 粘贴到公开 Issue。

## Markdown 中文文件名异常

最新版本使用 UTF-8 文件名。如果浏览器仍显示通用英文名，请更新浏览器后重试；文件内容不受影响。

## 如何提交问题

在结果页下载“诊断”文件，确认已经脱敏后，使用 GitHub Bug 模板提交。请附上：

- 留文版本；
- Windows 版本；
- 视频是否公开；
- 复现步骤；
- 错误提示；
- 脱敏诊断文件。
