# 留文 v0.6 Windows 便携版实施记录

日期：2026-07-24

## 目标

让内测用户在 64 位 Windows 10/11 上无需安装 Node.js、Python 或执行 PowerShell，即可双击运行留文。

## 已完成

- 新增独立桌面前端构建，将现有 React 界面编译为静态资源。
- Python 后端同时提供应用页面与 `/api` 接口，桌面版统一使用 `127.0.0.1:8765`。
- 保留开发模式：`localhost:3001` 仍会请求本地 `8765` 后端。
- 桌面版数据迁移到 `%LOCALAPPDATA%\WENL Scribe\data`。
- Whisper 模型集中保存到桌面版数据目录的 `models` 子目录。
- 新增系统托盘入口，支持“打开留文”和“退出留文”。
- 使用独立 Python 虚拟环境和 PyInstaller `onedir` 模式封装运行环境。
- 新增便携版 ZIP 构建脚本与面向用户的中文说明。

## 发行物

```text
release/WENL-Scribe-Portable-v0.6-win-x64.zip
```

便携文件夹约 244 MB，模型不包含在发行包中，会在首次选择和使用时下载。

## 验证结果

- 桌面静态前端构建成功。
- Sites/Vinext 原有生产构建成功。
- Node 测试 10/10 通过。
- Python 测试 7/7 通过。
- PyInstaller 发行构建成功。
- 已从发行目录实际启动 `WENL Scribe.exe`。
- `/api/health` 返回成功。
- 首页 HTML 和编译后的 JavaScript 均返回 HTTP 200。
- 测试完成后已关闭发行版进程并恢复原开发服务。
