留文 · WENL SCRIBE 便携内测版 v0.7.0

使用方法
1. 请先完整解压 ZIP，不要直接在压缩包内运行。
2. 双击“WENL Scribe.exe”。
3. 程序会自动打开浏览器；也可右键任务栏右下角的留文图标，选择“打开留文”。
4. 第一次使用某个 Whisper 模型时，需要联网下载模型文件。
5. 使用结束后，右键任务栏右下角的留文图标，选择“退出留文”。

v0.7.0 使用提示
- 每次新建转录都会先询问本次使用的 Whisper 模型，首次默认选择 Small。
- 第一次开始转录时需要确认内容权限、结果核对、本机资源和云端隐私说明。
- 结果页播放器支持缩略、拖动和自动弹出偏好；总结页默认位于左侧，完整转录页默认位于右侧。

数据位置
历史任务、总结配置和模型默认保存在：
%LOCALAPPDATA%\WENL Scribe\data

隐私与密钥
- 音频转录在本机完成。
- 如果启用 Gemini、SenseNova 或其他总结 API，带时间戳逐字稿会发送给所选服务商。
- API 密钥仅保存在本机应用数据目录。请勿截图或分享密钥。

已知限制
- 当前仅面向 64 位 Windows 10/11 内测。
- Windows 可能提示“未知发布者”；请只使用 GitHub 仓库 Release 页面提供的安装包。
- 首次下载模型及首次转录会比后续使用更慢。
